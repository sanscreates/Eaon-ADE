electron-updater against GitHub Releases. Downloads in the background, installs on restart. Squirrel.Mac takes the zip, never the dmg. A 404 or unreachable feed is classified as up-to-date rather than an error, because that is the normal state before the first release exists. Depends on [[Release and notarisation]].
